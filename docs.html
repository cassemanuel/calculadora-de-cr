Documentação

Entenda como a Calculadora de CR interpreta o boletim/histórico do SIGA/UFRJ e como usar as ferramentas de simulação.

Fórmula do CR

O SIGA/UFRJ calcula o Coeficiente de Rendimento (CR) como a média ponderada dos graus pelos créditos requisitados (CrR): 

CR = Σ(Grau × CrR) / Σ(CrR)

Apenas disciplinas que conferem grau entram no numerador e no denominador.

Situações tratadas

Situação (SF) Entra no CR? Comportamento
AP Sim Adiciona Grau × CrR ao numerador e CrR ao denominador.
RM / RF / RFM Sim Entram com grau 0, reduzindo o CR.
NCG / NCC / T Não Não computam nota, créditos ou pontos para o CR.
Cursando Não Disciplinas em andamento não entram no histórico concluído.

Importante: disciplinas com SF AP mas grau textual T, NCG ou NCC (ex: transferências aprovadas por equivalência) também são excluídas do CR.

Exemplo de validação

Resultado obtido ao processar um boletim real do SIGA:

  • Créditos acumulados exibidos no PDF: 196,0
  • CrR efetivo com grau: 190,0 (exclui 4 cr de transferência T e 2 cr de NCG)
  • Pontos acumulados: 1336,1
  • CR calculado: 1336,1 / 190,0 = 7,032 (a interface do SIGA pode arredondar para 7,0)

Simulador de próximo período

Na aba Histórico via PDF, após importar o boletim, você pode preencher as disciplinas do período atual (ou futuro) com notas previstas.

  • O CR do período é recalculado em tempo real.
  • O novo CR acumulado combina o histórico importado com as notas previstas.
  • O impacto mostra quanto o CR sobe ou desce em relação ao histórico.
  • Você também pode importar disciplinas pendentes do BOA.

Meta reversa

A meta reversa responde: “Qual média preciso tirar nas disciplinas restantes para atingir um CR alvo?” 

média necessária = (CR alvo × CrR total − pontos acumulados) / CrR restante

Se a nota necessária for negativa, você já está acima do CR alvo. Se for maior que 10, o CR alvo é inatingível com os créditos restantes.

Exportar e importar JSON

Os dados processados ficam salvos no localStorage do navegador. Para fazer backup ou transferir para outro dispositivo:

  • Exportar JSON: baixa um arquivo com o histórico parseado.
  • Importar JSON: carrega um arquivo previamente exportado e recalcula o CR.

Nenhum dado é enviado para servidores. Todo o processamento é local.

Formatos numéricos

A interface aceita tanto vírgula quanto ponto como separador decimal. Os resultados são exibidos no padrão brasileiro (vírgula).
